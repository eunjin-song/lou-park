# LOU Park

브라우저에서 강아지와 산책하는 파스텔 로우폴리 3D 공원입니다.

## 실행

```bash
cd lou-park
npm install
npm run play
```

브라우저에서 http://localhost:5173 을 엽니다. 같은 주소로 창을 하나 더 열면 서로 사람과 강아지가 보입니다.

`npm run play`는 웹 화면과 실시간 서버를 함께 켭니다. 서버만 따로 켜려면 `npm run server`, 화면만 켜려면 `npm run dev`입니다. 화면만 켜면 다른 사람과 연결되지 않습니다.

## 인터넷에 올리기

공개 화면은 같은 Node 서버가 만들고, 실시간 연결도 그 서버의 `/park` 경로를 사용합니다. 브라우저는 지금 보고 있는 주소로 접속하므로 공개 화면 코드에 localhost나 비밀값을 넣지 않습니다.

호스트가 넣는 환경변수:

- `PARK_PUBLIC=1` 이면 모든 네트워크에서 접속을 받고, 빌드된 화면을 함께 제공합니다.
- `PORT` 는 호스트가 지정한 포트입니다. 로컬 `npm run server`는 이 값을 쓰지 않고 `127.0.0.1:8787`을 유지합니다.
- `PARK_ALLOWED_ORIGINS` 는 쉼표로 구분한 허용 출처입니다. 비워 두면 요청의 공개 주소와 같은 출처만 허용합니다.

빌드와 실행:

```bash
npm install --include=dev
npm run build
```

호스트의 시작 명령은 `node server/index.ts`입니다. Node.js 22.18 이상이 필요합니다. 무료 Render 설정은 `render.yaml`에 있습니다. 15분 동안 아무도 없으면 잠들고, 다음에 열면 약 1분 뒤 다시 켜집니다. 한 달에 무료 실행 시간이 750시간이며, 잠든 시간은 포함되지 않습니다.

## 조작

- `W` `A` `S` `D` 또는 방향키로 이동합니다.
- 강아지는 사람 뒤를 따라옵니다.
- 울타리 밖으로 나갈 수 없습니다.
- 입장할 닉네임은 앞뒤 공백을 제외한 2~12자입니다. 한글·영문 등 문자, 숫자, 공백, `_`, `-`를 사용할 수 있습니다. 새로고침하면 이전 이름이 입력되어 있습니다.
- Enter로 대화를 열고 다시 Enter로 전송합니다. Esc로 입력을 취소합니다. 한글 조합 중 Enter는 전송하지 않습니다.
- 채팅 입력 중 이동과 카메라 조작은 잠깐 멈춥니다.
- 터치 화면은 왼쪽 조이스틱으로 걷고, 오른쪽 빈 화면을 드래그해 둘러봅니다. 키보드 조작은 그대로입니다.
- 입장하고 10분이 지나면 서버가 그 강아지의 배변을 한 번 만듭니다. 재접속은 새 입장이고 타이머가 다시 시작됩니다. 주인이 가까이서 `E` 또는 줍기로 담으면 봉투를 들고, 휴지통 옆에서 `E` 또는 버리기로 처리합니다.
- 놀이터 안에 들어가면 강아지가 울타리 안에서 놀고, 벤치 옆에서 `E` 또는 쉬기로 앉습니다. 걸으면 쉬기가 풀리고, 놀이터 밖으로 나오면 강아지가 다시 따라옵니다.
- 휴대폰에서는 https://lou-park.onrender.com 을 엽니다. 컴퓨터의 localhost 주소는 휴대폰에서 열리지 않습니다.
- 메시지는 최대 120자, 1초에 한 번입니다. 자신의 메시지를 포함하여 머리 위에 약 5초간 표시되며 새 메시지가 이전 메시지를 대체합니다.
- 닉네임은 이 브라우저에만 저장되고 채팅 기록은 저장하지 않습니다. 이름의 중복은 허용합니다.

## 닉네임·채팅 검증

`node server/run-chat-tests.ts`는 별도 서버(18788 포트)를 자동으로 시작하고 종료합니다. `node server/run-tidy-tests.ts`는 18789 포트에서 배변 타이머만 2.5초로 줄여 검사합니다. 공개 기본값은 10분이며 `render.yaml`에는 넣지 않습니다. 기존 공원 서버를 중단하지 않습니다.
닉네임·채팅 형식, 양방향 전송, 본인 수신, 발신자 ID 위조 방지, 빈도 제한, 위치 갱신 시 닉네임 유지, 최대 10명, 퇴장·재입장을 검사합니다.

프로토콜이 변경되었으므로 업데이트 후 기존 웹 화면과 실시간 서버를 모두 재시작해 주세요.
브라우저 2창의 말풍선 위치·겹침·만료 시간·입력 충돌·새로고침과 서버 중단 후 자동 재접속은 별도로 확인해야 합니다.

## 확인

1. 잔디, 순환 산책로, 나무, 연못, 벤치, 울타리가 보이는지
2. 사람과 강아지가 바닥에 서 있고 그림자가 있는지
3. WASD로 걸어 강아지가 따라오는지
4. 울타리까지 걸어 더 이상 나가지 않는지
